# PC BUILDER 2026 🖥️⚡

Профессиональный интерактивный веб-конфигуратор персональных компьютеров с поддержкой искусственного интеллекта **Google Gemini Pro**, актуальными ценами польских ритейлеров (Ceneo, Morele, x-kom) и многоуровневой системой валидации совместимости.

---

## 🌟 Ключевые возможности

1. **Интерактивная схема и слоты компонентов:**
   - 10 категорий комплектующих: CPU, Motherboard, Cooler, RAM, GPU, SSD, HDD, PSU, Case, Monitor.
   - Информационные подсказки `(?)` с инженерным описанием назначения каждой детали.
   - Прямой поиск и сравнение предложений в магазинах (Ceneo, Morele, x-kom, Amazon).

2. **🤖 Gemini Pro AI Консультант:**
   - Интерактивный диалоговый чат с поддержкой естественного языка.
   - Понимание специфических требований (белые сборки, стриминг, 4K монтаж, тихие ПК).
   - Прямое управление конфигуратором: найденные компоненты устанавливаются на схему на лету.

3. **⚖️ Анализ синергии и Bottleneck:**
   - Мгновенный расчет баланса связки CPU ↔ GPU для 1080p, 1440p и 4K.
   - Кнопка **«✨ Проверить сборку с AI»** для глубокого аудита шины PCIe, фаз питания VRM и стабильности 1% Low FPS.

4. **⚡ Матрица производительности (FPS Benchmark):**
   - Расчет реального фреймрейта в современных играх (CS2, Cyberpunk 2077, GTA V, Dota 2, RDR2 и др.) для 1080p, 1440p и 4K.

5. **📖 Энциклопедия железа (Hardware Guide):**
   - Всплывающее окно с инженерным разбором микроархитектур x86-64, кэша 3D V-Cache, цепей питания VRM, стандарта ATX 3.0 и прямого выбора в каталоге.

6. **❓ FAQ & Legal Notice:**
   - Ответы на частые вопросы по совместимости, разнице SSD vs HDD, выбору DDR4 vs DDR5.
   - Правовой дисклеймер, товарные знаки и гарантия конфиденциальности (LocalStorage).

## 🚀 Быстрый запуск

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/draconua/pc-builder.git
   cd pc-builder
   ```

2. **Запуск локального сервера:**
   ```bash
   node tools/dev_server.js
   ```

3. **Открыть в браузере:**
   Перейдите по адресу: [http://localhost:3000](http://localhost:3000)

## ⚙️ Настройка Gemini AI (Опционально)

Для работы функций PRO-консультанта и AI-синергии укажите ваш Google Gemini API ключ в файле `gemini_config.json`:
```json
{
  "GEMINI_API_KEY": "YOUR_GEMINI_API_KEY_HERE"
}
```
